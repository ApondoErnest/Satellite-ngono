# Satellite Ngono — design tokens

For Laravel Blade migration, reuse these CSS variables from [`css/tokens.css`](../css/tokens.css).

| Token | Value | Usage |
|-------|-------|--------|
| `--primary` | `#C41020` | CTAs, accents |
| `--primary-hover` | `#A30D1A` | Button hover |
| `--secondary` | `#0A1A45` | Topbar, footer, stats |
| `--accent` | `#1E4FD8` | Links (sparingly) |
| `--surface` | `#F7F8FA` | Section backgrounds |
| `--text` | `#1A1D26` | Body text |
| `--text-muted` | `#5C6370` | Secondary text |
| `--success` | `#0D7A4E` | Badges, validity |

**Typography:** DM Sans (headings), Source Sans 3 (body).

**Layout classes:** `sn-topbar`, `sn-header`, `sn-section`, `sn-card`, `sn-footer`, `sn-page-hero`.
